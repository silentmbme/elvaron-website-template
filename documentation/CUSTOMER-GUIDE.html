FIRST THINGS FIRST

Getting started

Elvaron is a static HTML template built with Vite, Bootstrap 5, SCSS, and JavaScript. You can preview and edit it locally before publishing it to your hosting provider.

  1. 1
    Install Node.js

    Use a current LTS release from nodejs.org.

  2. 2
    Open the project folder

    Open the folder containing package.json in your terminal or code editor.

  3. 3
    Install project packages
    TERMINAL 
    npm install

    On Windows PowerShell, use npm.cmd install if script execution blocks npm.

  4. 4
    Start the local preview
    TERMINAL 
    npm run dev

    Open the local address printed in the terminal. Keep the terminal running while you work.

↗

For a production preview: run npm run build, then npm run preview. The finished website is written to dist/.

02

KNOW YOUR WAY AROUND

Project map

Most edits belong in one of these places. Keep shared pieces in their partials so the same update reaches every page.

html/Page content and page structure
html/partials/Shared headers, footers, and components
src/scss/Colors, typography, layout, and component styling
src/js/Navigation, forms, theme controls, and page behavior
public/Fonts, icons, and static files copied to the build
dist/Generated site files ready for hosting

The site pages are discovered from html/ automatically. Shared partials live in html/partials/ and are expanded during the Vite build.

03

YOUR BRAND, YOUR DETAILS

Make it yours

Choose your colors

Use the on-page customizer to preview solid or gradient primary colors, light or dark appearance, and layout direction. The customizer saves your preview in this browser.

Keep type consistent

The visual system uses Bricolage Grotesque for headings and Hanken Grotesk for body text. Update the shared typography styles when changing font families or scale.

Replace the identity

Update the Elvaron name, logo mark, favicon, page titles, social links, and contact details wherever they appear in shared and page-specific content.

Use your own images

Place optimized images in src/assets/images/, use descriptive alt text, and keep image dimensions close to the displayed aspect ratio.

i

Preview versus permanent settings: The customizer saves choices in your current browser so you can preview them. To set the default for every visitor, update the DEFAULTS and palette values in src/js/components/theme-toggle.js. The Reset button restores those defaults.

Aa

Typography and identity: Update font families and responsive sizes in src/scss/base/_typography.scss. Update the logo in html/partials/headers/ and the favicon at public/assets/favicon.svg. See Typography customization for the full type scale.

The logo and contact details appear in shared header and footer partials. Change those shared files once instead of editing every page separately.

CONNECT YOUR SERVICES

Forms & integrations

Forms currently provide front-end validation and demo feedback. They do not send or store submissions.

Before accepting real inquiries

Connect the contact and newsletter forms to your chosen backend, CRM, or email platform. Test successful and failed submissions, update the privacy notice, and verify where messages are delivered.

  • Choose where messages go. Select your form provider, CRM, or server endpoint.
  • Connect each form. Update its action or wire it to your provider's API using the provider's instructions.
  • Test the full journey. Send a test message, confirm delivery, and check the success and error states on mobile.
  • Protect customer data. Publish an accurate privacy policy and collect only the information you need.

QUICK ANSWERS

Fix common issues

The page will not open or the styles look missing.

Start the Vite preview with npm run dev and open the address shown in the terminal. Do not open a source page directly from File Explorer; Vite expands the shared page parts and compiles the styles.

PowerShell says scripts are disabled.

Use npm.cmd install, npm.cmd run dev, or npm.cmd run build in PowerShell.

My logo, image, or font is missing.

Check the file name and path, including uppercase and lowercase letters. Keep the file in the intended assets folder and use the same path in your HTML or SCSS.

My live site looks different from the local preview.

Build again with npm run build, then upload the new contents of dist/. Also check that your host serves the site from the domain root, as the template uses root-relative links.
